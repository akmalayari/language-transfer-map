# Proficiency Levels

| Level | Label | Description | CEFR approx. |
|-------|-------|-------------|--------------|
| 0 | No knowledge | No vocabulary or grammar — not counted as a transfer source | — |
| 1 | Beginner | Can decode text slowly, ~50 words or fewer | pre-A1 |
| 2 | Elementary | Basic structures, ~100–300 words, simple exchanges | A1–A2 |
| 3 | Functional | Can handle real situations with effort | B1 |
| 4 | Comfortable | Conversations flow, specific gaps remain | B2–C1 |
| 5 | Fluent | Rarely stuck, natural expression | C1–C2 |
