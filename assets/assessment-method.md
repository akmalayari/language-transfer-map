# Assessment Method

## Principle

Adaptive, bottom-up. Start at the lowest level, stop when the user hits their ceiling. A language where you can't read the script takes 2 minutes. A language near the durability threshold takes 20.

## Two Tracks

Script ability and oral comprehension are independent — you can understand spoken Japanese without reading kanji. The assessment runs two parallel tracks.

| Track | What it measures |
|-------|-----------------|
| **Written** | Script decoding → reading comprehension → written production |
| **Oral** | Listening comprehension → speaking (self-reported) |

Each track produces its own level (0–5). The overall level is the **minimum across skills** — that's the real-world floor. But per-skill scores are recorded because they determine what the method should focus on.

## Reference Language

The assessor translates to/from whichever reference language fits best. Use whatever language the user is most comfortable in — French, English, Spanish, etc. The user may respond in any language they prefer.

## Procedure

### Step 1 — Script Gate + Listening Probe (Level 0 → 1)

Run both in parallel to establish the floor for each track.

**Written:** Show 5–10 common words in the language's native script. Ask the user to read/transliterate them.
- Pass (→ proceed to Step 2 written): can decode most words
- Fail (→ written Level 0): cannot decode the script

**Oral:** Say or play 10 common words. Ask the user to translate.
- Pass (→ proceed to Step 2 oral): recognizes ~6+/10
- Fail (→ oral Level 0): recognizes fewer than 3/10
- Partial (3–5/10 → oral Level 1): has fragments, not enough for sentences

### Step 2 — Vocabulary + Basic Sentences (Level 1 → 2)

Run for each track that passed Step 1.

**Written:** Show 15 common words (target → reference language). Then show 5 simple sentences, ask the user to explain the meaning.
- Pass (→ proceed to Step 3): ~10+/15 words correct AND understands 3+/5 sentences
- Partial (→ Level 1): knows words but can't parse sentences
- Production sub-test: ask the user to translate 5 simple sentences INTO the target language. Evaluate grammar, word order, accuracy.

**Oral:** Say or play 5 simple sentences. Ask the user to explain the meaning.
- Pass (→ proceed to Step 3): understands 3+/5
- Fail (→ oral Level 1): catches isolated words but not sentence meaning

### Step 3 — Functional Comprehension (Level 2 → 3)

**Written:** Present a short paragraph (4–6 sentences, everyday topic). Ask 3 comprehension questions.
- Pass (→ proceed to Step 4): answers 2+/3 correctly
- Fail (→ Level 2): gets the gist but misses key details

**Oral:** Play or read a short paragraph. Ask the user to summarize.
- Pass (→ proceed to Step 4): captures main idea + at least one detail
- Fail (→ oral Level 2): catches fragments only

**Production:** Ask the user to write 5 sentences on a prompted situation (e.g., "describe your morning" or "order food at a restaurant"). Evaluate grammar, vocabulary range, naturalness.
- Pass: functionally correct on 3+/5, communicative intent clear
- Fail: frequent structural errors, communication breaks down

### Step 4 — Comfortable Use (Level 3 → 4)

**Written:** Present a longer text (8–10 sentences, includes some nuance — opinion, condition, cause/effect). Ask 4 comprehension questions including one inferential.
- Pass (→ proceed to Step 5): answers 3+/4 correctly including the inferential one

**Oral:** Play or read a longer passage at natural pace. Ask for a detailed summary.
- Pass: captures main argument + supporting details + tone

**Production:** Write a paragraph (6–8 sentences) on a prompted topic. Evaluate: register, connectors, subordinate clauses, idiom, naturalness.
- Pass: reads like a comfortable speaker, minor errors only

### Step 5 — Fluency Check (Level 4 → 5)

**Written:** Present a text with subtle meaning — irony, implication, cultural reference. Ask interpretive questions.

**Production:** Write on an abstract or nuanced topic (e.g., "explain a decision you regret" or "argue for or against something"). Evaluate: idiom, register control, precision, natural flow.

- Level 5: native-like command, natural expression, rarely stuck
- Level 4: comfortable but occasional gaps, non-native patterns visible
